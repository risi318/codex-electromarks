# ElectroMarks

Веб-приложение для проектирования и печати маркировок электрических щитов.

## Возможности

- размещение и редактирование наклеек на схеме щита;
- настройка текста, цветов и пиктограмм;
- сохранение и открытие проекта в JSON;
- экспорт готовых листов в PDF.

## Запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm test
npm run build
```
